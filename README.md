# 🛰️ NEXUS CMD

### AI Satellite Mission Control & Predictive Risk Analysis Platform

NEXUS CMD is a full-stack aerospace mission control platform designed to monitor satellite constellations in real time, analyze telemetry streams, predict mission risks, and generate intelligent alerts before critical failures occur.

Inspired by modern mission control centers, the platform combines real-time monitoring, predictive analytics, interactive visualization, and AI-assisted decision support into a single operational dashboard.

---

# 🚀 Key Features

### 📡 Real-Time Telemetry Monitoring

Monitor live satellite telemetry including Battery Level, Temperature, CPU Utilization, Signal Strength, Power Consumption, and Communication Latency.

### 🤖 AI-Powered Risk Analysis

Analyze telemetry trends to calculate Health Scores, identify anomalies, classify threat levels, and predict potential satellite failures.

### 🚨 Intelligent Alert Center

Automatically detect critical conditions and generate actionable alerts for mission operators.

### 📈 Predictive Failure Forecasting

Estimate failure probabilities and recommend mitigation actions before mission-critical issues occur.

### ⏱️ Mission Timeline

Track alerts, events, telemetry deviations, and mission activities through a continuously updated event history.

### 🛰️ Satellite Fleet Management

Manage multiple satellites through a centralized command dashboard with operational status monitoring.

### 🌍 Interactive Orbit Visualization

Visualize satellites around Earth using an immersive 3D orbital tracking interface powered by Three.js.

### 🔐 Secure Authentication

Role-based access control using JWT authentication and protected routes.
